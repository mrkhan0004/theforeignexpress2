THE FOREIGN EXPRESS — IELTS PERMISSION PASSWORD

Initial IELTS Permission Master Password:
TFE-Ielts@2026#Access

HOW TO CHANGE IT
1. Open admin.html and sign in to the admin panel.
2. Open Settings and find “IELTS PERMISSION MASTER PASSWORD”.
3. Enter TFE-Ielts@2026#Access in “Previous / Current Password”.
4. Enter a new password (at least 6 characters) and confirm it.
5. Click “Update Permission Password”.
6. Use the new password whenever granting or revoking IELTS access.

COMPATIBILITY FIX
Older installations that have an empty permission password now fall back to the initial password above. This avoids the blank-password initialization problem.

IMPORTANT SECURITY NOTICE
This project is a static GitHub Pages website and currently uses browser localStorage. The password is present in public frontend JavaScript and is NOT a secure production secret. Anyone can inspect or modify frontend code and browser storage. Do not use this starter password to protect real student records or paid access. For production, implement authentication, permission checks, and payment verification on a trusted backend. Change this starter password for convenience, but understand that changing it in frontend storage does not create real security.
